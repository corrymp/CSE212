# Trees
## binary trees
- collection of nodes
- each node has at most two child nodes
- root node = node without parent (node at top of tree)
- leaf node = node without children

```
      |A| <- root
      / \
    |B| |C| <- parent of F
    / \   \
  |D| |E| |F| <- child of C
  / \   \
|G| |H| |I| <- leaves: F,G,H,I

subtree of B: D,E,G,H,I
```

## binary search tree
- nodes placed using rules
- data < parent: place to left
- data > parent: place to right
- duplicates: not allowed or  either
- O(log n) lookups

```
adding: 20

        |15| <- greater than: go right
        /  \
     |10|  |24| <- less than: go left
     /  \     \
   |3|  |14|  |33|
            ^ 20 goes here
```
- can be unbalanced (leading to O(n) lookups)
```
|3|
  \
  |10|
     \
     |14|
        \
        |14|
           \
           |20|
              \
              |24|
                 \
                 |33|
```

## balanced binary search tree
- only small height diff between nodes in subtree
```
            |15|
            /  \
         |10|  |24|
         /  \     \
H=2 -> |3|  |14|  |33|
            /
H=3 ->   |12|
            \
            |13| <- H=4
            
rebalanced
            |15|
            /  \
         |10|  |24|
         /  \     \
H=2 -> |3|  |13|  |33|
            /  \
H=3 ->   |12|  |14| <- H=3
```

## inserting
- recursive
  - smaller task: insert left or right then move down layer
  - base case: ends when a space is found
```cs
public class BinarySearchTree : IEnumerable<int> {
    private Node? _root;
    public void Insert(int val) {
        if(_root is null) _root = new Node(val);
        else _root.Insert(val);
    }
}

public class Node {
    public void Insert(int val) {
        if(val < Data) {
            if (Left is null) Left = new Node(val);
            else Left.Insert(val);
        }
        else {
            if(Right is null) Right = new Node(val);
            else Right.Insert(val);
        }
    }
}
```

## traversing
- recursive
  - smaller task: go down left subtree, then right subtree
  - base case: end at empty subtree

```cs
var bst = new BinarySearchTree();
foreach(var val in bst) Console.WriteLine(val);

public class BinarySearchTree : IEnumerable<int> {
    private Node? _root;

    IEnumerator IEnumerable.GetEnumerator() => GetEnumerator();

    public IEnumerator GetEnumerator() {
        var nums = new List();
        TraverseForward(_root, nums);
        foreach(var num in nums) yield return num;
    }

    private void TraverseForward(Node? node, List values) {
        if(node is not null) {
            TraverseForward(node.Left, values);
            values.Add(node.Data);
            TraverseForward(node.Right, values);
        }
    }
}
```

## common operations
op                  perf        desc
insert(val)         O(log n)    add val to tree
remove(val)         O(log n)    remove val from free
contains(val)       O(log n)    check val in tree
traverse_forward    O(n)        visit all nodes small -> large
traverse_reverse    O(n)        visit all nodes large -> small
height(node)        O(n)        get height of node
size()              O(1)        size of tree
empty()             O(1)        true if size == 0
